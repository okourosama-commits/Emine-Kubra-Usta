# Emine Kübra Usta — Academic website

Static academic website for Emine Kübra Usta. Two pages: `index.html` and `publications.html`, plus a CV PDF at `docs/Emine_Kubra_Usta_Academic_CV.pdf`.

## Publish to GitHub Pages
1. Create a **public** GitHub repository named `emine-kubra-usta` under your account.
2. Upload **all files and folders inside this directory to the repository root** (not the ZIP file itself). This includes `index.html`, `publications.html`, `assets/`, `docs/` and `.nojekyll`.
3. In the repository, go to **Settings → Pages → Build and deployment**.
4. Choose **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**, then **Save**.
5. After GitHub finishes deploying, your default address should be `https://<your-github-username>.github.io/emine-kubra-usta/`.
6. Open the homepage, Publications and the CV download to verify everything.

## Updating content
- `index.html`: homepage
- `publications.html`: bibliography
- `assets/style.css`: layout, typography and colors
- `assets/emine-kubra-usta-portrait.jpg`: approved café portrait
- `docs/Emine_Kubra_Usta_Academic_CV.pdf`: downloadable CV

The website uses only local HTML/CSS and does not require a build process or external dependencies. The site is not published just because these files exist; publishing requires adding them to GitHub and enabling Pages.
